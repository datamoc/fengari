Pyroeis

Du Lua dans vos applications JavaScript, avec un budget d’exécution décidé par le code hôte.

Une VM Lua 5.4.6 pour le navigateur et Node.js, un compilateur numérique optionnel et un outil pour traduire vos sources Lua en JavaScript.

npm install @datamoc/pyroeis

Un projet indépendant issu de Fengari

Pourquoi notre interface d’échange JavaScript ↔ Lua ? Le contrat des données, les fonctions exposées à Lua et les différences avec fengari-interop.

Pyroeis poursuit son propre développement à partir du travail de Benoit Giannangeli, Daurnimator et des contributeurs de Fengari. Les crédits et la licence MIT sont conservés.

Le langage actuellement implémenté est Lua 5.4.6. Le passage à Lua 5.5.1 est en cours. Les limites d’exécution complètent le préréglage de sandbox ; les callbacks JavaScript que vous fournissez restent sous votre responsabilité.

const { PyroeisVm } = require('@datamoc/pyroeis');
const vm = new PyroeisVm(undefined, undefined, {
  sandbox: true,
  limits: { instructions: 100000, timeMs: 100 }
});
console.log(vm.run('return 6 * 7')); // 42
