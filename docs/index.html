The currently implemented language is Lua 5.4.6. The move to Lua 5.5.1 is in progress. Execution limits complement the sandbox preset; the JavaScript callbacks you provide stay your responsibility.Le langage actuellement implémenté est Lua 5.4.6. Le passage à Lua 5.5.1 est en cours. Les limites d’exécution complètent le préréglage de sandbox ; les callbacks JavaScript que vous fournissez restent sous votre responsabilité.

const { PyroeisVm } = require('@datamoc/pyroeis');
const vm = new PyroeisVm(undefined, undefined, {
  sandbox: true,
  limits: { instructions: 100000, timeMs: 100 }
});
console.log(vm.run('return 6 * 7')); // 42
