Fengari vs JavaScript

Lua 5.4 running in @datamoc/fengari compared with the same algorithms written in plain JavaScript. Everything runs in your browser, right now.

Fengari is a Lua interpreter written in JavaScript: every Lua instruction is executed by JavaScript code, while the native JavaScript versions below are compiled to machine code by your browser's JIT. Expect Lua-in-Fengari to be much slower on tight numeric loops. This page measures exactly how much, so you can decide whether Fengari fits your workload (scripting, rules, configuration, game logic) or not (number crunching).

Ready. A full run takes about 10 to 30 seconds and the page may freeze briefly while each Lua benchmark runs.

Method

Each benchmark runs the same algorithm in both languages with the same input size and returns a checksum; the last column checks that both agree. JavaScript times are averaged over enough repetitions to last at least 80 ms (browsers coarsen performance.now()). With 3 or 5 runs, one untimed warm-up run is done first and the median of the timed runs is reported. The Lua side is called through FengariVm with only the base, string, table and math libraries opened.
