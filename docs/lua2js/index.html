      What to know
      
  
      Arrays are shifted to 0-based, nil is undefined, if x becomes truthy(x) because Lua treats 0 and "" as true, and multiple returns become arrays. Literal Lua patterns become RegExp calls; metatables, coroutines, patterns using %b or %f, general goto and 64-bit bitwise operators are not translated. The benchmark executes the translated code in this page, so only run Lua you wrote or trust.
