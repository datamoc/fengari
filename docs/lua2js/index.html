Lua ↔ JavaScript

Paste Lua, get readable JavaScript you can keep. Translation runs in your browser; nothing is uploaded.

This is the offline translator behind lua2js and PyroeisVm.toJs() from Pyroeis. It prints idiomatic JavaScript from the Lua source and marks with TODO(lua2js) whatever it cannot translate faithfully. The benchmark below runs the same function as Lua in Pyroeis's interpreter and as the translated JavaScript. See also the Pyroeis vs JavaScript benchmark.

    What to know
    
  
    Arrays are shifted to 0-based, nil is undefined, if x becomes truthy(x) because Lua treats 0 and "" as true, and multiple returns become arrays. Literal Lua patterns become RegExp calls; metatables, coroutines, patterns using %b or %f, general goto and 64-bit bitwise operators are not translated. The benchmark executes the translated code in this page, so only run Lua you wrote or trust.
