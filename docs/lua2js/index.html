        What to knowÀ savoir
        
  
        Arrays are shifted to 0-based, nil is undefined, if x becomes truthy(x) because Lua treats 0 and "" as true, and multiple returns become arrays. Literal Lua patterns become RegExp calls; metatables, coroutines, patterns using %b or %f, general goto and 64-bit bitwise operators are not translated. The benchmark executes the translated code in this page, so only run Lua you wrote or trust.Les tableaux passent en base 0, nil devient undefined, if x devient truthy(x) car Lua considère 0 et "" comme vrais, et les retours multiples deviennent des tableaux. Les motifs Lua littéraux deviennent des appels RegExp ; métatables, coroutines, motifs utilisant %b ou %f, goto général et opérateurs bit à bit 64 bits ne sont pas traduits. Le benchmark exécute le code traduit dans cette page : n’y lancez que du Lua écrit par vous ou de confiance.
